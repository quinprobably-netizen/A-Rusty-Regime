# Comic UI Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build piece 1 of the comic redesign: a `ComicTheme` resource, the look-A fonts and a set of comic widget spawners that the later HUD and menu work builds on. No existing screen changes in this plan.

**Architecture:** A new `src/comic/` module with a `ComicPlugin`. `theme.rs` holds the tokens and font handles. `halftone.rs` is one `UiMaterial` for dot fills. `widgets.rs` holds plain spawner functions in the style of `menu::text` and `hud::plate`. `sfx.rs` holds the pop-word animation. Tilt uses `UiTransform`, and hard shadows use `BoxShadow` with zero blur.

**Tech Stack:** Rust 2024, Bevy 0.19 (`bevy::ui_render::prelude::{UiMaterial, MaterialNode, UiMaterialPlugin}`, `UiTransform`, `BoxShadow`), WGSL.

**Spec:** `docs/superpowers/specs/2026-10-28-comic-redesign-design.md` (section "Look A: tokens" and "1. Comic kit").

## Global Constraints

- Colours: ink `#111111`, paper `#F6EDD6`, red `#E23A2E`, yellow `#FFD23F`, blue `#2B5FAD`, navy `#14213D`, orange `#E07A3F`, green `#3FA34D`, muted `#6B5E4A`.
- Fonts: Bangers (display) and Barlow Condensed SemiBold + ExtraBold (body), OFL, in `assets/fonts/`, each with its `OFL.txt`, and listed in `CREDITS.md` per the repo's `CLAUDE.md` asset rule.
- Ink borders 4 to 7 px; shadows are hard (`blur_radius: Val::ZERO`), ink-coloured, 4 to 7 px offset. Tilts stay within -3..3 degrees, except `sfx_pop`.
- Sizes are in 1080p px; Bevy's `UiScale` scales them, and the kit adds no scale of its own.
- No new crate dependencies.
- Tests live in `#[cfg(test)] mod tests` inside each new file, as `quartermaster.rs` does. `cargo test --release` must stay green apart from the known-flaky `a_held_player_still_resets_and_respawns_after_a_fall`.

## Review Focus

1. A font file is missing or renamed, so text should still render in Bevy's default font, never as blank. Owned by Task 2.
2. Stat values outside 0..1 or NaN come from `gunsmith::stats` maths. The bar should clamp and never draw negative or overflowing widths. Owned by Task 4.
3. Pips for a weapon with no magazine (knife, power fist: mag 0) or a very large one. The expected result is zero pips, or at most 30 pips plus a "+N" label. Owned by Task 4.
4. Health above max or below zero (overheal, death frame) should leave the segment bar filled 0..=segments. Owned by Task 4.
5. An SFX pop fired just before the game pauses (`Time<Virtual>` is paused in menus) should still finish and despawn, never hang on screen. Owned by Task 5.

### Task 3: Halftone material

- Create: `src/comic/halftone.rs`, `assets/shaders/halftone.wgsl`
- Modify: `src/comic/mod.rs` (add `UiMaterialPlugin::<Halftone>::default()`)

**Interfaces:**
- Produces: `#[derive(AsBindGroup, Asset, TypePath, Clone)] pub struct Halftone { #[uniform(0)] pub fill: LinearRgba, #[uniform(0)] pub dot: LinearRgba, #[uniform(0)] pub params: Vec4 }`. `params` holds x = pitch px, y = dot radius px, z = angle radians, w = 0. `impl UiMaterial` uses `fragment_shader() -> "shaders/halftone.wgsl"`.
  `pub fn halftone_layer(materials: &mut Assets<Halftone>, fill: Color, dot: Color, pitch: f32, radius: f32) -> impl Bundle` returns an absolute 100%×100% `Node` plus a `MaterialNode`, to be spawned as a panel's first child.
  `pub fn halftone_params(pitch: f32, radius: f32) -> Vec4` clamps pitch to 4..=64 and radius to 0.5..=pitch/2.

- [ ] **Step 1: Failing test** `params_are_clamped`: `halftone_params(1.0, 9.0) == Vec4::new(4.0, 2.0, 0.0, 0.0)` and `halftone_params(12.0, 3.0) == Vec4::new(12.0, 3.0, 0.0, 0.0)`.
- [ ] **Step 2: Run** `cargo test --release comic::halftone` and expect FAIL.
- [ ] **Step 3: Implement.** The shader imports `bevy_ui_render::ui_vertex_output::UiVertexOutput`. It takes `p = in.uv * in.size` and rotates it by `params.z`. Then `cell = fract(p / pitch) - 0.5`, `d = length(cell) * pitch`, and it returns `mix(dot, fill, smoothstep(r - 0.75, r + 0.75, d))`.

### Task 4: Widgets

**Files:**
- Create: `src/comic/widgets.rs`

**Interfaces:**
- Consumes: `ComicTheme`, `display_text`, `body_text` (Task 2), `halftone_layer` (Task 3).
- Produces (all take `p: &mut ChildSpawnerCommands, theme: &ComicTheme` first and return the spawned `Entity`):
  - `panel(p, theme, fill: Color, tilt_deg: f32) -> Entity`: ink border `ink_px`, `BoxShadow` with offset `shadow_px` and zero blur, and `UiTransform::from_rotation(Rot2::degrees(tilt))`.
  - `caption(p, theme, text: &str) -> Entity`: a yellow panel, tilted -2 degrees, with ExtraBold body text.
  - `bubble(p, theme, text: &str, tail: Tail) -> Entity`, where `pub enum Tail { Left, Down }`: a white panel with a 24 px radius and a 28×28 ink triangle node.
  - `stat_bar(p, theme, label: &str, base: f32, now: f32) -> Entity`: a row with the label, a value, and a bar where ink fills `min(base, now)`, blue fills the gain up to `now`, and red fills the loss up to `base`.
  - `segment_bar(p, theme, value: f32, max: f32, segments: usize) -> Entity`: red filled segments with paper-coloured empty ones.
  - `pip_row(p, theme, loaded: u32, mag: u32) -> Entity`: yellow filled pips and outlined empty ones.
  - `hint_strip(p, theme, hints: &[(&str, &str)], money: Option<u32>) -> Entity`: an ink strip whose glyph circles are green for "A", red for "B" and paper for anything else, with money at the right in yellow as `¢ 2,450`.
  - Pure helpers, which hold the logic the tests pin: `pub fn bar_spans(base: f32, now: f32) -> (f32, f32, f32)`, returning (ink, gain, loss) widths in 0..=1; `pub fn filled_segments(value: f32, max: f32, segments: usize) -> usize`; `pub fn pips(loaded: u32, mag: u32) -> (u32, u32, u32)`, returning (filled, empty, overflow); `pub fn money(c: u32) -> String`.
